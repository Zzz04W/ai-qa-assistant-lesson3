# 第 3 课 · AI 智能问答助手与课程知识库搭建

> 从 30 条原始 FAQ 到可运行、可打分、会拒答的问答助手。

一个零依赖、可离线运行的单文件问答助手，配套完整知识工程成果与评测报告。

## 在线体验

直接用浏览器打开 `06_问答助手.html` 即可使用，无需安装、无需联网、无需 API Key。
页面内置 6 个示例问题按钮，覆盖别名问法、越界问法与无命中问法。

## 功能

- **答案卡片**：显示命中条目 id、匹配得分、命中的别名/关键词、来源行号。
- **越界拒答**：命中 8 类越界规则时，立即停止匹配并显示兜底话术。
- **低置信度拒答**：最高匹配得分低于 0.35 时拒答，不编造课程政策。
- **并列处理**：多个条目得分并列时显示前 2 条并提示人工确认。

## 文件结构

| 文件 | 说明 |
| --- | --- |
| `01_语料体检报告.md` | 30 条原始语料的 6 项统计、问题明细与清洗映射 |
| `02_规范问答集.csv` | 去重规范化后的 19 条问答 |
| `03_知识库.json` | 17 条结构化知识条目 |
| `04_拒答规则.md` | 8 条越界规则与阈值/并列处理 |
| `05_规则配置.json` | 规则配置的机器可读版本 |
| `06_问答助手.html` | 单文件问答助手（主产物） |
| `07_评测报告.md` | 20 题评测与修订前后对比 |
| `08_评测结果.csv` | 逐题跑分结果 |
| `09_维护与对接说明.md` | 维护流程与回归要求 |
| `10_制作说明.md` | 能力清单与复现摘要 |
| `11_自评得分表.md` | 100 分量规自评 |
| `scripts/` | 数据生成、匹配引擎、跑分与校验脚本 |

## 复现

```bash
python scripts/prepare_data.py
python scripts/build_html.py
python scripts/eval_runner.py
python scripts/validate.py
```
